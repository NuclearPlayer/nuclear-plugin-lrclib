# LRCLIB plugin for Nuclear

Lyrics provider for [LRCLIB](https://lrclib.net), a free, open database of synced lyrics. No account required.

The plugin returns line-synced lyrics when LRCLIB has them, and plain lyrics otherwise. Tracks that LRCLIB marks as instrumental show as instrumental.

## Installation

Install from the Nuclear plugin browser.
